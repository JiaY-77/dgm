# dgm — 文本图表工具（状态机 / 流程图 → PNG）

几行文本 → 一张排版干净的 PNG。

```dgm
title: 订单状态机 · 状态流转
entry 下单成功 @1,1
key   待付款   @2,1 | 买家还没付款
end   已完成   @3,1
warn  已取消   @2,3 | 终态

下单成功 -> 待付款: 创建订单
待付款 -> 已取消: 超时未付款 ~-40
```

```bash
dgm order.dgm -o order.png
```

## 为什么不用 mermaid / D2

两个现成工具各有一块硬伤（实测结论，同一张 5 状态 + 8 条边的状态机）：

- **mermaid**：布局引擎是 dagre，双向边挤在同一通道、条件标签压线，调 `nodeSpacing` 只能缓解，始终挤。
- **D2**：TALA 布局确实好，但视觉风格（配色 / 圆角 / 阴影 / 字号）基本改不动，想贴合自己的设计规范没门。

dgm 反着来：**位置人手定**（`@列,行`，CSS Grid 排版），**连线自动算**（浏览器读元素位置画贝塞尔），**风格全在你手里**（模板就是一个 HTML 文件，改 CSS 即可）。代价是坐标要自己填——对十几二十个节点以内的图，这比调自动布局的脾气快得多。

## 安装

```bash
pip install dgm-diagram
```

需要 Python 3.10+、Pillow（自动装）和本机的 Edge 或 Chrome（PNG 截图用）。

## 用法

```bash
dgm input.dgm -o out.png            # 基本用法（默认 2 倍清晰度）
dgm input.dgm -o out.png --scale 3  # 更清晰
dgm input.dgm -o out.png --html out.html   # 保留可交互 HTML（浏览器打开能看连线动画）
dgm --check input.dgm               # 只解析不渲染，校验语法（报错带行号）
dgm --version
```

报错长这样（指到行号，顺便给修正建议）：

```
第 12 行语法错误：边定义缺少 "->"
  已驳回 已取消
  ^^^^^^^^^^^^^^^^^
提示：应该是  已驳回 -> 已取消: 标签
```

## DSL 语法

一份例子看全：

```
# 注释
title: 标题
subtitle: 副标题
gap: 104,112                  # 列间距,行间距

entry 下单成功 @1,1            # 类型 名称 @列,行
key   待付款     @2,1 | 描述    # | 后面是节点描述
end   已完成     @3,1
warn  已驳回     @2,3 | 终态

group 主流程: 待付款, 已完成    # 自动画虚线包围框

下单成功 -> 待付款: 创建订单    # A -> B: 标签
待付款 -> 已取消: 超时 ~-40     # ~N 控制连线弯曲像素，不改变锚点位置
a <-> b: 同步                  # 双向边（展开成来回两条）

legend 事件: entry             # 图例 标签: 类型
```

节点类型（决定配色，样式见 `src/dgm/templates/base.html`）：

| 类型 | 用途 |
|---|---|
| `entry` | 胶囊，入口事件 |
| `key` | 进行中的关键状态 |
| `end` | 终态 |
| `warn` | 异常 / 只读状态 |
| `plain` | 普通节点 |

要点：

- **`@列,行` 建议都写**。工具不做自动布局（刻意取舍，见上）；不写 `@` 的节点会堆到第 1 列
- 位置是 1 起始的行列号，稀疏格子会留白，尽量把每行每列填满
- 双向关系建议写两条边各配 `~`（一正一负），拉成两条平行线更清楚
- `~` 只控弯曲幅度，不负责修断头——锚点由布局自动决定：同行/同列落在重叠范围中点，斜对角贴边走正交折线，端点始终在节点边框上

## 局限

- 没有自动布局：大图（几十节点）手摆坐标会很累，这种请用 D2
- 节点名和描述不做 HTML 转义：含 `<` `>` `&` 的文字会坏排版，避开即可
- PNG 依赖本机浏览器：自动探测的是 Windows 下 Edge / Chrome 的常见安装路径，其他平台用 `--edge /path/to/browser` 或设 `DGM_BROWSER` 环境变量
- 中文排版按微软雅黑 / 苹方调的，其他字体没验证过
